# Hotel Booking Cancellation Prediction

## Project Overview

This project focuses on understanding, cleaning, and preprocessing hotel booking data to prepare it for machine learning modeling and analysis.
The main goal was to practice working with real-world datasets, explore data patterns, handle data quality issues, and build a complete preprocessing pipeline before training prediction models.

## Objectives

* Understand the dataset structure and relationships between features.
* Perform data cleaning and preprocessing.
* Handle missing values, duplicates, and inconsistent data.
* Detect and treat outliers.
* Apply feature engineering techniques.
* Prepare the dataset for machine learning models.
* Analyze factors related to hotel booking cancellations.

## Dataset

The dataset contains hotel booking information such as:

* Booking status
* Customer information
* Reservation dates
* Number of guests
* Room types
* Special requests
* Booking lead time
* Cancellation details

## Data Preprocessing & Analysis

During this project, several preprocessing and analysis steps were applied, including:

* Data exploration and understanding
